## Running the benchmark

```bash
mamba env create -f environment_benchmarks.yml
mamba activate @@ENV_NAME@@
python -m pip install -r requirements.txt
docker build -t benchmark @@SOFTWARE_DIR@@/container
apptainer build benchmark.sif docker-daemon://benchmark:latest
export BENCHMARK_CONTAINER=$PWD/benchmark.sif
cd @@SOFTWARE_DIR@@
python run_benchmark.py --benchmark-file ../@@BENCHMARK_FILE@@ --result-path ./results
```

`run_benchmark.py` runs the Snakemake workflow for every configuration in the
container and packs the runs into an aggregate RO-Crate. The
[@@SOFTWARE_NAME@@ CI](.github/workflows/run-benchmark-@@SOFTWARE_DIR@@.yml) does
the same on every push and checks that every configuration wrote every metric.
